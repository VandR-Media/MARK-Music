# MARK Music

Приватный офлайн-аудиоплеер для Huawei Pura 80 Ultra, названный в честь Марка.

Ранний этап: исходный код, 20 визуальных эффектов, локальная медиатека, фоновое воспроизведение. APK публикуется только после успешной сборки.

Технологии: Kotlin, Jetpack Compose, Media3, MediaStore. Интерфейс — русский.
