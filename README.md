# MARK Audio

MARK Audio — офлайн-аудиоплеер для Android на Kotlin, посвящённый Марку.

## Возможности версии 0.5.1
- Медиатека на основе MediaStore: треки, альбомы, исполнители и папки; поиск и сортировка по дате добавления.
- Локальное воспроизведение через Media3 ExoPlayer и фоновая MediaSession.
- Встроенные обложки, мини-плеер, перемотка, переход между треками.
- 20 режимов аудиореактивной визуализации из PCM-потока проигрывателя; разрешение на микрофон не требуется.
- Работа без интернета и без GMS. Интерфейс на русском языке.

## Проверка
Сборка: GitHub Actions → тесты, debug APK (для установки и проверки) и release APK без подписи; файлы доступны в Artifacts после успешной сборки.
Поддержка аудиоформатов зависит от декодеров Android. APE, DSD, WMA и другие редкие форматы пока не гарантируются.
Совместимость с Huawei Pura 80 Ultra / EMUI 15 предстоит проверить на устройстве.

## Технологии
Kotlin 2.2.20, Android Gradle Plugin 8.11.1, Gradle 8.13, Media3 1.11.1, Jetpack Compose, AndroidX. minSdk 26 / targetSdk 35 / compileSdk 36.

Исходный код — ранняя тестовая версия, без утверждений о пройденной сборке до проверки GitHub Actions.

Статус: автоматическая сборка и тесты запускаются для Pull Request; APK выдаётся только после успешной проверки.


Branding 0.2.0: approved MARK Audio logo and tagline — Feel the sound. See the music.

- Плавность и точность совмещения фото-катушек необходимо проверить на Huawei Pura 80 Ultra.

## MARK Audio 0.7.9 — кассетный магнитофон «Весна-202-1»

Третья визуализация в экране «Сейчас играет»:

- **Винил** — исходная пластинка и тонарм с обложкой в центре.
- **Маяк-203** — фотографический катушечный магнитофон с вращающимися катушками.
- **Весна-202-1** — фотографический кассетный магнитофон из предоставленного пользователем фронтального референса: аутентичные решётка динамика, лицевая панель, механические клавиши, стрелочный прибор, кассета и надписи.

Переключение остаётся горизонтальным свайпом по изображению. Влево: Винил → Маяк → Весна → Винил; вправо — в обратном порядке. Плавный переход 370 мс, как и в 0.7.8. Три индикатора-«точки» указывают выбранный экран; выбор сохраняется после перезапуска.

У кассеты **вращаются только две ступицы внутри её реальных отверстий**. Сама кассета, этикетка, кнопки и корпус неподвижны. Скорость намотки соответствует условной стандартной скорости протяжки 4,76 см/с: принимающая и подающая ступицы имеют разную угловую скорость по мере изменения количества ленты. При паузе/уходе приложения в фон визуальное движение останавливается. Для отображения уровня звука не требуются разрешения RECORD_AUDIO или дополнительная обработка звука.

Фотографический фон загружается и проверяется по SHA-256 **только на сборочном сервере**, после чего полностью включён в подписанный APK. Android-приложение остаётся офлайн. На Huawei Pura 80 Ultra остаётся проверить точность совмещения ступиц и плавность работы.

**Лицензия:** фото «Весна-202-1» пользователь предоставил в качестве референса для приватной разработки. Разрешение на публичное распространение этой фотографии в составе приложения не подтверждено; до публикации за пределами личного тестирования потребуется проверить права.

## MARK Audio 0.7.11 — 8 музыкальных аппаратов, настоящие таймеры и VU-индикаторы

К уже доступным виниловому проигрывателю, «Маяку-203» и «Весне-202-1» добавлены пять отдельных фотоаппаратов:
CD-проигрыватель с лазерной головкой, MiniDisc, профессиональный DAT, ламповый радиоприёмник и Jukebox.

**Навигация:** свайпы влево/вправо с прежней анимацией 370 мс, циклический переход по восьми аппаратам и сохранение выбора при перезапуске.

**Фотографическое оформление:** пять оригинальных сгенерированных для MARK AUDIO художественных фотоконцептов из переписки пользователя. Они хранятся в репозитории как Base64-кодированные WebP с закреплёнными SHA-256, автоматически помещаются в APK в ходе сборки и **не загружаются из сети во время работы**. Их нельзя представлять как фотографии подлинных моделей производителя.

**Механика:** диск CD с отдельной неподвижной лазерной головкой, вращающийся MiniDisc, два DAT-шпинделя с изменением скоростей по намотке, виниловая пластинка в механизме Jukebox и подсветка лампового радио. Анимация синхронизирована с кадрами без пропуска кадров короче 9 мс, останавливается при паузе и в фоне.

**Функциональные дисплеи и индикаторы:**
- Таймеры CD, MiniDisc и DAT отображают **реальную позицию воспроизведения Media3**, MiniDisc дополнительно показывает общую длительность и название композиции.
- Play подсвечивается при воспроизведении, Pause — при приостановке; на аппаратах без собственных кнопок Play/Pause подсветка соответствует устройству (радиолампы и Jukebox).
- Стереоиндикаторы MiniDisc и DAT вычисляют **реальные RMS уровни левого и правого PCM-канала** через проходной Media3 TeeAudioProcessor без RECORD_AUDIO и без Android Visualizer API. Частота обновления ограничена ~30 Гц, замеры отключаются, когда аппарат скрыт или плеер на паузе. В радио и Jukebox яркость ламп зависит от той же измеренной энергии музыки. Это НЕ синтетический эквалайзер, а динамический индикатор уровня звука.
- Поскольку напрямую декодированный PCM может быть недоступен для passthrough/offload, индикаторы в этом случае честно показывают отсутствие данных, а не случайный сигнал. Оригинальные аудиофайлы никак не изменяются.

**Важное уточнение:** после технической проверки APK необходимо протестировать вид анимаций, расположение подсветки и совместимость аудиотракта с Huawei Pura 80 Ultra. Метрики 120 FPS и отсутствие нагрева нельзя подтвердить на GitHub Actions.
