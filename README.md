# MARK Audio

MARK Audio — офлайн-аудиоплеер для Android на Kotlin, посвящённый Марку.

## Возможности версии 0.5.1
- Медиатека на основе MediaStore: треки, альбомы, исполнители и папки; поиск и сортировка по дате добавления.
- Локальное воспроизведение через Media3 ExoPlayer и фоновая MediaSession.
- Встроенные обложки, мини-плеер, перемотка, переход между треками.
- 20 режимов аудиореактивной визуализации из PCM-потока проигрывателя; разрешение на микрофон не требуется.
- Работа без интернета и без GMS. Интерфейс на русском языке.

## Проверка
Сборка: GitHub Actions → тесты, debug APK (для установки и проверки) и release APK без подписи; файлы доступны в Artifacts после успешной сборки.
Поддержка аудиоформатов зависит от декодеров Android. APE, DSD, WMA и другие редкие форматы пока не гарантируются.
Совместимость с Huawei Pura 80 Ultra / EMUI 15 предстоит проверить на устройстве.

## Технологии
Kotlin 2.2.20, Android Gradle Plugin 8.11.1, Gradle 8.13, Media3 1.11.1, Jetpack Compose, AndroidX. minSdk 26 / targetSdk 35 / compileSdk 36.

Исходный код — ранняя тестовая версия, без утверждений о пройденной сборке до проверки GitHub Actions.

Статус: автоматическая сборка и тесты запускаются для Pull Request; APK выдаётся только после успешной проверки.


Branding 0.2.0: approved MARK Audio logo and tagline — Feel the sound. See the music.

## Брендинг 0.5.1
- Эталонный PNG-логотип MARK Audio используется как единый источник для значка приложения и шапки.
- Отдельный утверждённый PNG приветственного экрана показывается при запуске.
- Старые векторные заглушки значка удалены; CI проверяет целостность WEBP-ресурсов после декодирования.
- Debug APK подписывается стандартным Android debug-сертификатом; release APK в CI остаётся неподписанным до настройки личного release-keystore. Предупреждение Huawei нельзя считать устранённым одной заменой значка.

## MARK Audio 0.7.5 — Hi-Fi Turntable
- Плавное вращение винила на каждом кадре дисплея (включая 120 Гц) без прежнего пропуска кадров при интервале меньше 9 мс.
- Угол рассчитывается по реальному времени кадров, скорость остаётся 33⅓ об/мин.
- Поворот выполняется на графическом слое без пересоздания композиции и отрисовки 256 канавок на каждом тике.
- Матовые и полированные металлические детали, виниловая поверхность, мягкие отражения, переработанный противовес и тонарм.
- Декоративная неоновая стеклянная рамка вокруг проигрывателя заменена на сдержанную металлическую.
- Добавлены модульные тесты скорости вращения при 60/90/120 Гц и паузе.

**Важно:** высокий FPS, отсутствие рывков и внешний вид ещё необходимо проверить на реальном Huawei Pura 80 Ultra. CI-сборка сама по себе не является проверкой производительности устройства. Подписанный release-APK зависит от отдельного процесса подписи.

## MARK Audio 0.7.6 — Катушечный магнитофон «Маяк»

- В разделе «Сейчас играет» нажми на подпись **MARK AUDIO · ВИНИЛ ⌄ / МАЯК ⌄**, чтобы открыть диалог выбора проигрывателя.
- **Винил** остаётся исходным вариантом, с обложкой или логотипом на этикетке.
- **Маяк-203** — вторая самостоятельная визуализация: деревянный корпус, тёмная верхняя панель, две металлические катушки, видимая лента, магнитные головки, светлая лицевая панель и два стрелочных прибора.
- Катушки синхронизированы с кадрами экрана, плавно вращаются при воспроизведении и останавливаются на паузе/в фоне. Диаметр намотки меняется по прогрессу трека; на принимающей и подающей катушках разные угловые скорости.
- Выбранная визуализация сохраняется между запусками. Новый режим не меняет медиатеку, плейлисты, эквалайзер, фоновой сервис, доступ к данным или разрешения.
- Внешний вид **вдохновлён** моделью «Маяк-203», это не точная техническая 3D-копия. Декоративные стрелочные индикаторы отражают режим Play/Pause, **не являются** измерением уровня сигнала.
- На Huawei Pura 80 Ultra нужно визуально проверить размеры, плавность и фактический FPS. Подписанный релиз собирается существующим workflow с секретами и проверкой сертификата.

## MARK Audio 0.7.7 — фотореалистичный «Маяк» и свайпы
- Старый диалог выбора проигрывателя полностью удалён. Переключение **Винил ↔ Маяк-203** делается горизонтальным свайпом влево или вправо **по области визуализации**; две точки внизу показывают выбранную визуализацию.
- Выбор, как и прежде, сохраняется после перезапуска.
- «Маяк» больше не рисуется упрощёнными градиентами, геометрическими кнопками и векторными катушками. Используется реальная историческая фотография магнитофона с вращающимися фотографическими фрагментами катушек. Вся фотография статична, только катушки вращаются GPU-трансформациями.
- Исправлено обрезание второй строки «MARK AUDIO» под заголовком «СЕЙЧАС ИГРАЕТ».
- Для воспроизводимости фотография загружается **во время сборки** в ресурсы APK, а не во время воспроизведения: приложение остаётся полностью офлайн и не запрашивает разрешение Интернет.
- Источник фото: [Majak203.jpg, Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Majak203.jpg), фотограф Віктор Ходєєв (Viktor Khodyeyev), 2018, передано автором в public domain. Скрипт: `scripts/fetch-mayak-photo.py`.
- Для сборки на чистой машине требуется одноразовый доступ к Wikimedia Commons из Gradle/CI; подписанный release проходит прежнюю проверку разрешений и сертификата.
- Плавность и точность совмещения фото-катушек необходимо проверить на Huawei Pura 80 Ultra.

- Исходное изображение магнитофона используется для персонального проекта по переданному пользователем референсу; название автора и условия дальнейшего распространения необходимо уточнить перед публикацией приложения в магазине.
