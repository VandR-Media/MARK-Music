# MARK Audio 0.7.28 — независимый тест Music Major API

## Цель
Проверить собственный OAuth-клиент «Только API» `017187c1377846eb80cedcd93cf3fd38` с сохранёнными разрешениями `music:api-public` и `music:major-public-api`. Это не существующий Android LoginSDK Client ID.

## Изоляция
- Исходный Яндекс ID, пользовательский Music OAuth и прежний API-type OAuth не меняются.
- Проверяемый поток PKCE S256 использует отдельные зашифрованные ключи `major_pending` и `major_token` в Android Keystore AES-GCM.
- Токен не выводится в UI, логи или репозиторий, response body Music API не сохраняется.
- Нет фоновых повторов, попыток получения треков, скачивания или воспроизведения защищённого контента.
- При сетевой ошибке запрос не повторяется автоматически.

## Пошаговая аппаратная проверка
1. Установить проверенный подписанный MARK Audio 0.7.28 только после успешной CI и проверки подписи. Не удалять старое приложение/его данные.
2. Открыть «Медиатека → Яндекс Музыка → Music Major API · эксперимент».
3. Нажать «Подключить Music Major». В браузере Яндекса выдать доступ собственному зарегистрированному клиенту. Код не присылать в чат.
4. Вернуться в MARK Audio и ввести выданный код в поле приложения. Не делиться им, не сохранять его в скриншотах.
5. После сообщения о сохранении токена нажать «Проверить Client ID и совпадение аккаунта». **Без совпадения аккаунта диагностический запрос недоступен.**
6. При подтверждённом совпадении нажать «Один диагностический запрос /account/status» и сообщить только обезличенный результат: HTTP 200/401/403/429 или ошибка сети.
7. При необходимости нажать «Отключить Music Major», что удалит только новые экспериментальные записи из локального хранилища.

## Интерпретация
- Успешный OAuth/Яндекс ID означает, что код обменян, а токен соответствует своему Client ID/пользователю; это **не** доказательство доступа к музыкальному каталогу.
- Если /account/status возвращает 403, одной из возможных причин остаётся серверное право/политика клиента, но точная причина не известна.
- Даже ответ 200 не даёт лицензии на получение/проигрывание аудиопотоков и не подтверждает право на остальные методы.
- Endpoint /account/status известен из неофициальных реализаций. Его использование здесь ограничено добровольной диагностикой и не является публичной спецификацией для продакшн-плеера.
