# MARK Cosmic — производство игрового 3D-персонажа

**Статус: в разработке. Новая художественная модель пока не готова.**

См. задачу #30 и открытые черновые PR #31 и #32.

## Утверждённый образ

Персонаж — стильный мультяшный мальчик по согласованной трёхракурсной MARK Cosmic-иллюстрации, вдохновлённой предоставленными владельцем фотографиями. Задача — узнаваемость, естественные пропорции и живые ткани, а не сборка тела из шаров.

- Красная кепка с белой M, короткие тёмные волосы.
- Большие наушники с неоновым ободом и фирменной буквой M.
- Тёмно-синее худи с цветной звуковой волной, настоящими складками и карманом.
- Серые брюки-карго с тканевой фактурой, кроссовки со шнурками и подсветкой.
- Органическая сетка лица с глазами, веками, бровями и аккуратно стилизованной мимикой.
- Космическая сцена — отдельный фон, не запечённый в модель.

**Запрещено:** собирать персонажа из примитивов и выдавать красивый 2D-рендер за готовый rigged GLB.

## Производственный процесс

1. Blender: органический скульпт головы и тела и ручная ретопология под анимацию лица и сгибов суставов.
2. Одежда отдельно, с контролируемыми швами, складками и силуэтом; аксессуары можно жёстко привязывать к костям.
3. UV0, PBR: baseColor, normal, roughness/metallic, emissive для наушников и деталей обуви.
4. Общий humanoid-скелет, плавные веса skinning, корректные плечи/локти/колени, контроль контакта стоп и root motion.
5. Мимика: минимум BlinkLeft, BlinkRight, Smile, MouthOpen; затем дополнительные эмоции.
6. Две диагностические анимации: Idle_Breathe и NPC_Wave на настоящем скелете.
7. Экспорт из Blender в автономный GLB 2.0 с включёнными текстурами и прогон автоматического валидатора.

## Автоматическая проверка модели

| Свойство | Условия первого допуска |
|---|---|
| Полигональный бюджет LOD0 | 15–75 тысяч треугольников |
| Скелет | 50–110 deform-костей, цель 60–90 |
| Общий размер GLB | Не более 35 МиБ |
| Материалы | UV0 + normals; минимум три embedded PBR-текстуры |
| Весовые деформации | Не менее 8% skinned-вершин имеют два существенных веса |
| Лицевая мимика | Четыре названные blend shape |
| Короткие клипы | Idle_Breathe, NPC_Wave |

Это **предварительные ориентиры**, а не измеренные пределы Huawei.

Валидатор: python3 scripts/character/validate_character.py /private/export/MarkCosmic.glb --json

Экспортёр: blender -b /private/mark_cosmic.blend --python scripts/character/export_character_blender.py -- /private/export/MarkCosmic.glb

Исходный Blender-проект должен содержать коллекцию MARK_COSMIC_EXPORT: только персонаж, его одежда, аксессуары и скелет; без сценических референсов, фотографий и посторонних объектов.

## Три обязательных этапа приёмки

**A. Корректная модель:** GLB проходит валидацию по каркасу, весам, UV, PBR, лицевым формам и NPC-клипам. Прототип 0.7.12 / Stage 1 (22 кости, 0 текстур, 0 UV, 0 лицевых morph targets) не проходит. Скрипт сам по себе не доказывает качества лица или красивой анимации.

**B. Художественное утверждение:** только кадры из настоящей экспортированной 3D-модели: фронт, профиль, спина, крупно лицо/ткань и тест сгибов. Не использовать AI-иллюстрации в качестве доказательства готового GLB. До утверждения не включать модель в APK.

**C. Проверка на Huawei:** после B — подключение профессионального 3D-рендерера (основной кандидат Filament), тест материалов, скелета, CPU/GPU, памяти, батареи и FPS на реальном Pura 80 Ultra.
