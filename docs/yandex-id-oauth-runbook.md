# MARK Audio 0.7.19 — официальный Яндекс LoginSDK на Huawei

## Статус

MARK Audio использует официальный Android **Yandex LoginSDK 3.3.0** вместо собственного браузерного OAuth/PKCE. Клиент зарегистрирован владельцем приложения в Яндекс OAuth под Android:

- **Client ID (публичный):** `cfaacee8ff6d4941a5966d00c53a61de`
- **Android applicationId:** `com.markmusic.player`
- **SHA-256:** отпечаток закреплённого релизного сертификата из GitHub Actions. Нужно подтвердить на экране Яндекс OAuth соответствие всего отпечатка, а не только видимой части.
- **Scope:** `login:info` (доступ к логину, имени и фамилии, полу).
- Данные `YANDEX_CLIENT_ID` и `YANDEX_OAUTH_HOST` зафиксированы в `app/build.gradle.kts`; отдельный ввод Client ID в плеере больше не требуется.
- **Client secret, пароль и персональный OAuth-токен не сохраняются в GitHub**.

Официальные источники: https://yandex.ru/dev/id/doc/ru/mobileauthsdk/android/3.1.3/sdk-android-use и https://central.sonatype.com/artifact/com.yandex.android/authsdk/3.3.0 .

## Использование на Huawei Pura 80 Ultra (EMUI 15)

1. Установить **подписанный Release APK 0.7.19 из main** поверх текущей версии MARK Audio. Debug APK имеет суффикс пакета `.preview2` и **не соответствует** пакету, зарегистрированному в Яндекс OAuth.
2. Открыть MARK Audio → **Медиатека** → **Яндекс Музыка** → **«Войти с Яндекс ID»**.
3. Официальный SDK пытается использовать приложение Яндекса с сохранённым аккаунтом; если его нет, переходит в системный браузер/Chrome Custom Tabs или WebView. Наличие Google Play Services не требуется для авторизации по заявленной схеме, но реальная работа на Huawei должна быть отдельно проверена.
4. Подтвердить доступ **только к профилю**. После возврата в MARK Audio ожидается надпись `Яндекс ID: <логин>`.
5. Нажатие **«Отключить Яндекс ID»** удаляет локальный токен из Android Keystore-шифрованного хранилища. Для отзыва доступа на стороне Яндекса воспользуйтесь управлением авторизованными приложениями Яндекс ID.

## Почему старая ошибка 400 теперь не должна повториться

В версии 0.7.18 использовался собственный браузерный Redirect URI `markaudio://oauth/yandex`, который не совпадал с Callback URL на сервере Яндекса. В 0.7.19 **эта Activity и старые PKCE-классы удалены**, а возврат обрабатывает официальный LoginSDK и его Android manifest. Не нужно добавлять веб-платформу или выдумывать HTTP callback.

## Безопасность и ограничения

- Токены принимает только Android LoginSDK и передаёт в модуль проверки профиля через `Authorization: OAuth <token>`; значение не показывается UI и не попадает в логи.
- MARK Audio проверяет данные через `https://login.yandex.ru/info?format=json` с отключёнными HTTP-редиректами; подтверждённый токен шифруется AES/GCM с ключом Android Keystore.
- Соединение ограничено HTTPS; без внешней авторизации локальная музыка, Suno-импорты, ExoPlayer и визуализации остаются рабочими.
- Вход в **Яндекс ID не предоставляет доступ к потокам Яндекс Музыки**. Каталог/стриминг будут добавляться отдельно после получения разрешённого API.
- Автоматический CI подтверждает сборку и тесты, но реальное прохождение авторизации на Huawei без GMS нельзя считать доказанным до проверки владельцем.
- Для проверки подписи Android OAuth требуется, чтобы Яндекс OAuth сохранил **правильные** package name и SHA-256 релизного сертификата. Для Debug/Preview пакет другой.

## Если LoginSDK возвращает ошибку

Проверьте: сохранены ли Android Package Name и SHA-256, разрешён ли `login:info`, используется ли signed Release APK из main, доступен ли интернет. Зафиксируйте **только код ошибки/текст на экране**, без токена, URL с параметрами, Client secret или личных данных. Не используйте неофициальные OAuth-клиенты.
